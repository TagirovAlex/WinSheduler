# История изменений

## 2.1.2 — 2026-11-09

Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.2

### Исправлено

- После импорта, создания, изменения, удаления или включения задачи
  планировщик не сбрасывал кэш расписания. Задача не запускалась по
  расписанию до перезапуска службы; ручной `RunNow` работал.
  Теперь IPC уведомляет планировщик (`TaskChanged` → `on_task_changed`).
- Импортированные задачи с `hasPassword = true` по-прежнему создаются
  выключенными: пароль нужно задать вручную и включить задачу.

### Добавлено

- «Справка → Проверить обновления»: сравнение версии с `latest.json`
  на шаре; пункт виден только при заданном `UpdateUrl`.
- Автоустановка: еженедельная проверка, проверка SHA256 и Authenticode,
  резервная копия БД на шару, тихая установка MSI и перезапуск UI.

### Сборка и поставка

- MSI, `WinShedulerSvc.exe` и `WinSheduler.UI.exe` подписаны Authenticode
  сертификатом AD CS (Code Signing), метка времени DigiCert.
- `UpdateUrl` записывается в `HKLM\SOFTWARE\WinSheduler` при установке.
- Комплект обновления публикуется на `\\intsrvfs\winsheduler`;
  хранятся текущая и две предыдущие версии MSI.
- SHA256 подписанного MSI:
  `3A91AA06592713AB5CE11E4F958C9C3A9314DC49A65F10FF11AA1552CA7F13FA`.

## 2.1.1 — 2026-11-07

Косметический релиз интерфейса.

### Изменено

- Главное меню: «Файл / Вид / Действия / Справка».
- Панель действий с полным набором кнопок без overflow:
  добавить, изменить, удалить, включить/отключить, журнал, запустить,
  обновить, экспорт, импорт, диагностика.
- Поиск и фильтр — второй строкой слева, поля одинаковой высоты,
  выровнены по вертикали.
- Статус-бар внизу; диагностика перенесена в панель действий.
- Баннеры ошибок скрываются через `Collapsed` и не оставляют пустого места.
- Адаптивная ширина: окно стартует по ширине строки кнопок; таблица
  растягивается звёздными колонками; maximise заполняет экран без полос.
- XAML-дизайнер VS 2026: design-time guard’ы, явные pack URI иконок,
  стабильная панель действий.

### Сборка

- Поддержка VS 2022/2026 (toolset по умолчанию).
- UI multi-target: `net8.0-windows` для дизайнера, `net10.0-windows` для релиза.

## 2.1.0 — 2026-11-06

Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.0

### Добавлено

- Экспорт задач в `*.wstasks.json`: одна задача или несколько выбранных.
- Импорт задач с предпросмотром и режимами «копия», «пропустить»,
  «обновить свои». Пароли и служебные поля в файл не попадают.
- Автообновление статуса выполнения: после ручного запуска и для задач
  с `running=true` список сам показывает завершение или ошибку, без F5.
- Колонка «Статус» различает «Выполняется», «Ошибка», «Включена/Отключена»;
  в «Последнем запуске» отображается результат с цветовым индикатором.
- Иконки `export` и `import` в общем стиле приложения.

### Изменено

- UI и тесты переведены на **.NET 10 LTS**; UI остаётся self-contained.
- Минимальная ОС снижена до **Windows 10 1607 / Server 2016 (build 14393)**.
- Управляемая сборка переведена на `dotnet build`; C++ собирается MSBuild.
- Версия продукта — 2.1.0.

### Безопасность

- Экспорт не содержит `password`, `encryptedPassword`,
  `runAsPasswordEncrypted`, `owner`, `createdAt`, `modifiedAt`.
- Импорт не принимает пароли из файла: задача с `hasPassword` создаётся
  выключенной и требует ручного ввода пароля.
- ID триггеров при импорте очищаются, повторный импорт копии не ломает БД.
- Не-админ импортирует задачи только себе; перезапись чужих задач запрещена.

### Ограничения

- Только headless-задачи; интерактивный режим зарезервирован.
- Подпись кода отсутствует: выпускается SHA256-манифест.
- UI требует Desktop Experience; на Server Core работает только служба.
