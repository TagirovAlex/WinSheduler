# История изменений

## 2.1.0 — 2026-11-06

### Добавлено

- Экспорт задач в `*.wstasks.json`: одна задача или несколько выбранных.
- Импорт задач с предпросмотром и режимами «копия», «пропустить»,
  «обновить свои». Пароли и служебные поля в файл не попадают.
- Автообновление статуса выполнения: после ручного запуска и для задач
  с `running=true` список сам показывает завершение или ошибку, без F5.
- Колонка «Статус» различает «Выполняется», «Ошибка», «Включена/Отключена»;
  в «Последнем запуске» отображается результат с цветовым индикатором.
- Иконки `export` и `import` в общем стиле приложения.

### Изменено

- UI и тесты переведены на **.NET 10 LTS**; UI остаётся self-contained.
- Минимальная ОС снижена до **Windows 10 1607 / Server 2016 (build 14393)**.
- Управляемая сборка переведена на `dotnet build`; C++ собирается MSBuild.
- Версия продукта — 2.1.0.

### Безопасность

- Экспорт не содержит `password`, `encryptedPassword`,
  `runAsPasswordEncrypted`, `owner`, `createdAt`, `modifiedAt`.
- Импорт не принимает пароли из файла: задача с `hasPassword` создаётся
  выключенной и требует ручного ввода пароля.
- ID триггеров при импорте очищаются, повторный импорт копии не ломает БД.
- Не-админ импортирует задачи только себе; перезапись чужих задач запрещена.

### Ограничения

- Только headless-задачи; интерактивный режим зарезервирован.
- Подпись кода отсутствует: выпускается SHA256-манифест.
- UI требует Desktop Experience; на Server Core работает только служба.

## 2.0.2 — 2026-11-02

- Обновление поверх установленной версии, `AllowSameVersionUpgrades`.
- Закрытие UI перед установкой, нормализация путей, проверка ОС.

## 2.0.0 — 2026-11-01

- Первый MSI-релиз: служба, self-contained UI, группа, ACL.
