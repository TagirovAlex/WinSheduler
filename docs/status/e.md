## Выполнено

### E-1. Главное окно (`MainWindow`)

- Переведено на `App.Services.Ipc` и `DashboardViewModel`: один batch-вызов
  `GetDashboardAsync`, вызовов 2N+1 нет.
- Поиск по названию и пути, фильтр «Все / Мои / Включённые / Отключённые»,
  сортировка по колонкам (`DataGrid` + `ICollectionView`).
- Колонки: «Название», «Программа», «Владелец», «Статус», «Расписание»,
  «Последний запуск»; для выполняющейся задачи — «Выполняется».
- Действия: «Обновить», «Добавить», «Изменить», «Удалить», «Журнал»,
  «Запустить», «Включить/отключить». Все действия дублируются в контекстном меню.
- Горячие клавиши из `ShortcutCatalog`: F5, Ctrl+N, Enter, Delete, Ctrl+R.
- Пустое состояние: «Задач пока нет» либо «Ничего не найдено» с пояснением.
- Ошибки — баннером `StatusBannerError` с кнопками «Повторить» и «Открыть службы»;
  ошибки действий (удаление, запуск, переключение) — отдельный баннер.
- Статус-бар: состояние службы, роль, число задач, время обновления.

### E-2. Редактор задачи (`TaskEditorWindow`)

- Конструктор принимает `IIpcService`, `Guid?` и имя задачи; загрузка выполняется
  до редактирования через `GetTaskAsync` (расписание — из `TimeWindows`, при
  необходимости `GetTimeWindowsAsync`). До загрузки «Сохранить» недоступна.
- Валидация: название, путь программы и рабочая папка (локальный абсолютный путь,
  без UNC, device paths, `..`, альтернативных потоков и корня диска), повторы
  `0…10`, таймаут `0…10080`, история `1…10000`, пароль при указанном пользователе.
- Dirty tracking: снимок `TaskDto` до правок; при закрытии с несохранёнными
  изменениями — подтверждение через `IDialogService`.
- Пароль: поле `PasswordBox`, индикатор «Пароль задан / не задан / будет снят»,
  кнопка «Очистить». В `TaskDto` передаётся только `password` (write-only);
  `RunAsPasswordEncrypted` и `CryptoHelper` больше не используются.
- Для headless — подпись «Headless: окно не отображается на рабочем столе».
- Вкладка «Расписание»: добавление, изменение, удаление, дублирование
  (кнопка, контекстное меню, Ctrl+D, Del, Enter), пустое состояние.
- ComboBox’ы стиля окна, действия при ошибке и наложении — из перечислений
  с русскими подписями через `EnumTextConverter`.

### E-3. Диалог триггера (`TimeWindowDialog`)

- Пять типов, поля только выбранного типа, наложение полей интервала устранено.
- Общие ограничения: дата начала, дата конца, «Повторять до» (дата + время),
  «Включено».
- Валидация `ЧЧ:ММ`, диапазонов, дублей, порядка дат; ошибки — встроенный баннер.
- Предпросмотр summary; все строки — из `Strings.resx`, даты локальные.

### E-4. Журнал (`HistoryWindow`)

- `IIpcService.GetHistoryAsync` (лимит 1000), локальные даты `dd.MM.yyyy HH:mm:ss`.
- `DataGrid` с колонками «Начало», «Конец», «Статус», «Код», «Длительность»,
  «Ошибка»; цвет статуса — `RunStatusToBrushConverter`.
- Фильтр по статусу, F5, экспорт CSV (UTF-8 BOM, `;`), «Открыть лог» только для
  `.log`, пустые состояния, строка «Записей: N · обновлено …».
- Ошибки — баннером; путь к чужому файлу в сообщении не раскрывается.

### E-5. Диагностика (`DiagnosticsWindow`) — частично

- `IIpcService.GetStatusAsync`, роль из `IElevationService`, версия UI/службы,
  uptime, число задач, состояние подключения, копирование сведений.
- Раздел «Расположение данных» и «Аудит» — задел: показываются только админу;
  аудит загружается через `GetAuditAsync` с фильтром по датам. Служба в `main`
  ещё не реализует `GetAudit` и не отдаёт пути, поэтому отображается пояснение.

### E-6. Первый запуск и офлайн

- Баннер «Служба недоступна» с инструкцией (`services.msc`, `sc start WinSheduler`),
  кнопки «Повторить» и «Открыть службы», причина ошибки.
- Действия блокируются, пока служба недоступна; пустое состояние первого запуска.

### E-9. Владелец, админ-бейдж, elevation

- Колонка «Владелец» (`OwnerLabel` из `DashboardTaskDto`: «Вы» / «Другой пользователь»).
- Бейдж «Требует права администратора» и кнопка «Запустить от администратора»
  (`IElevationService.RelaunchAsAdmin`) в статус-баре для не-админа.
- В редакторе группа «Запуск от пользователя» недоступна без
  `CanManageSystemTasks` и помечена бейджем «Требует админа».

## Блокеры

1. **Дефект D-2 ломает запуск UI.** `Styles/Tokens.xaml` объявляет
   `Border_Width` как `Double`, а `Styles/Controls.xaml` подставляет его в
   `BorderThickness`. Любой стиль из дизайн-системы даёт `XamlParseException`
   (`"1" не является допустимым значением для свойства "BorderThickness"`),
   реальный `WinSheduler.UI.exe` падает при старте. Подробности и точное
   исправление — `./docs/status/e-requests.md`. Это блокирует приёмку E-1/E-2/E-9
   в реальном окне, но не сборку и не gate.
2. **Служба в `main` всё ещё legacy.** Нет `GetDashboard`, `SetTaskEnabled`,
   `GetAudit`, `Ping`, v2-фрейминга; `IIpcService` не может с ней работать.
   До слияния B-3…B-8 главное окно и журнал показывают «Служба недоступна».

## Расхождения с контрактами

1. `TimeWindowDto.SpecificDates` — `List<DateTime>` в `Shared`; UI передаёт
   полночь, `IpcDateTimeConverter` пишет `yyyy-MM-dd`. Контракт соблюдён на
   уровне JSON, но тип модели расходится с контрактом.
2. `TimeWindowDto` содержит legacy `Type` и новый `Kind`; UI заполняет оба.
3. Очистка пароля отправляет `password: ""`; семантика пустой строки не
   зафиксирована в контракте (запрос к Track B).
4. Служба пишет локальное время с суффиксом `Z`; UI трактует `Z` как UTC.
