# Протокол статусов

Каждый трек ведёт свой файл `./docs/status/<track>.md`. Это единственный файл, который агент трека правит в `./docs/status/`.

## Шаблон

```
# Статус трека <X>

## Текущая задача
<ID и название>

## Выполнено
- ...

## В работе
- ...

## Осталось
- ...

## Проверки
- ./scripts/verify.ps1 -Scope <track> — успешно/ошибка

## Блокеры
- ...

## Запросы к другим трекам
- ...
```

## Правила

- `./docs/plan/TASKS.md` правит только Integrator.
- `./docs/status/gate.md` правит только Gatekeeper.
- Запросы на правку чужих файлов — в `./docs/status/<track>-requests.md`.
- Блокировка дольше 30 минут — статус `[!]` и переход к следующей независимой задаче.
- Секреты и пароли в статусы не попадают.
