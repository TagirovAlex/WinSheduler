# Контракт UI

Статус: заморожен. Изменения — только через ADR.

## 1. Принципы

- Язык интерфейса — русский. Все строки — через `resx`, без литералов в XAML и коде.
- MVVM: логика в ViewModel/сервисах, code-behind — только навигация и события представления.
- Один визуальный стиль: токены, стили, иконки — в общем словаре.
- Минимализм: никаких неработающих контролов. Если функция не реализована — контрол скрыт или недоступен с пояснением.
- Доступность: клавиатура, `AutomationProperties`, читаемые подписи.
- DPI: корректная работа при 100–200%, минимальное окно 1024×700.

## 2. Токены

| Токен | Значение |
|-------|----------|
| Отступы | 4 / 8 / 12 / 16 / 24 |
| Высота контрола | 28 |
| Иконка | 16 (монохром, Segoe Fluent Icons) |
| Шрифт | Segoe UI, 12; заголовок 16 semibold |
| Радиус | 4 |
| Кнопка | `Padding=12,4`, `MinWidth=90`, без фиксированной `Width` |
| Цвет успеха | `#107C10` |
| Цвет ошибки | `#C42B1C` |
| Цвет предупреждения | `#9D5D00` |
| Нейтральный текст | `SystemColors.GrayTextBrush` |
| Фон | системные кисти, поддержка тёмной темы через `DynamicResource` |

Стили: `PrimaryButton`, `SecondaryButton`, `DangerButton`, `ToolbarButton`, `FormLabel`, `FormTextBox`, `FormComboBox`, `DataGridStyle`, `EmptyState`, `StatusBanner`.

## 3. Экраны

### MainWindow

- Список задач: колонки «Название», «Программа», «Владелец», «Статус», «Расписание», «Последний запуск».
- Панель действий: «Обновить», «Добавить», «Изменить», «Удалить», «Журнал», «Запустить», «Включить/Отключить».
- Поиск по названию и пути, фильтр «Все / Мои / Включённые / Отключённые», сортировка по колонкам.
- Контекстное меню дублирует действия.
- Горячие клавиши: F5 — обновить, Ctrl+N — добавить, Enter — изменить, Del — удалить, Ctrl+R — запустить.
- Пустое состояние: пояснение и кнопка «Добавить задачу».
- Статус-бар: состояние службы, число задач, время последнего обновления.

### TaskEditorWindow

- Вкладки: «Основные», «Расписание», «Параметры».
- «Основные»: название, описание, программа, аргументы, рабочая папка, стиль окна, учётные данные.
- «Расписание»: список триггеров, добавить/изменить/удалить/дублировать, summary.
- «Параметры»: при ошибке, повторы, при наложении, таймаут, kill, лог вывода, лимит истории.
- Для headless: `WindowStyle` доступен, но рядом подпись «окно не отображается на рабочем столе».
- Пароль: поле «Пароль», индикатор «пароль задан», кнопка «Очистить». Пароль никогда не показывается.
- Сохранение недоступно, пока данные не загружены; при несохранённых изменениях — подтверждение закрытия.
- Валидация: обязательные поля, `HH:mm`, диапазоны, дубли, числа.

### TimeWindowDialog (TriggerEditor)

- Типы: «Однократно», «Ежедневно», «Еженедельно», «Ежемесячно», «Интервал».
- Поля показываются только для выбранного типа; нереализованные контролы отсутствуют.
- «Однократно»: дата + время.
- «Ежедневно»: каждые N дней + список времён.
- «Еженедельно»: каждые N недель + дни недели + список времён.
- «Ежемесячно»: число + каждые N месяцев + список времён.
- «Интервал»: начало, конец, каждые N минут.
- Общие: дата начала, дата конца, повторять до (дата+время), включено.
- Валидация и предпросмотр summary.

### HistoryWindow

- Колонки: «Начало», «Конец», «Статус», «Код», «Длительность», «Ошибка».
- Локальный формат дат `dd.MM.yyyy HH:mm:ss`.
- Фильтр по статусу, обновление, экспорт CSV, «Открыть лог» (если есть `outputPath`).
- Длинная ошибка — тултип.

### DiagnosticsWindow / About

- Версия службы и UI, uptime, состояние подключения, `DATADIR`/`INSTALLDIR` (только админ), размер БД, последние ошибки.
- Аудит (только админ): фильтр по дате, действию, результату.
- Ссылка на документацию и лицензию.

## 4. Состояния

| Состояние | Отображение |
|-----------|-------------|
| Загрузка | прогресс-индикатор, кнопки disabled |
| Пусто | `EmptyState` с пояснением |
| Ошибка | `StatusBanner` с кодом и текстом, кнопка «Повторить» |
| Служба недоступна | баннер + инструкция запуска службы |
| Нет прав | баннер «Требуются права администратора» + кнопка elevation |
| Только чтение | контролы disabled, пояснение |

Модальные `MessageBox` — только для подтверждения разрушительных действий. Ошибки — в баннере.

## 5. Права и админ-режим

- UI работает `asInvoker`.
- В статусе показывается роль: «Оператор» / «Администратор».
- Для привилегированных действий: бейдж «Требует админа», кнопка «Запустить от администратора» (relaunch с `runas`).
- Не-админ видит только свои задачи; колонка «Владелец» показывает «Вы» или «Другой пользователь» (SID скрыт).
- Задачи от SYSTEM помечаются бейджем.

## 6. Локализация

- `Strings.resx` — русский по умолчанию; ключи в формате `Area_Element`.
- Форматирование дат/чисел — `CultureInfo("ru-RU")`.
- Ошибки службы: по `code` выбирается русский текст; `message` — fallback.
- Запрещены строки в XAML, кроме `x:Uid`/ресурсных ссылок.

## 7. Доступность

- Все интерактивные элементы доступны с клавиатуры, порядок табов логичный.
- `AutomationProperties.Name` для иконок и кнопок без текста.
- `Label Target` для полей ввода.
- Контраст текста не ниже 4.5:1.
- Иконки не являются единственным носителем смысла.

## 8. Производительность UI

- Один batch-запрос `GetDashboard` на обновление; никаких 2N+1 вызовов.
- Обновление не блокирует UI-поток; отмена при повторном запросе.
- Список виртуализирован; `ObservableCollection` вместо сброса `ItemsSource`.
- Иконки кэшируются; изображения 16 px, без масштабирования 32→16.

## 9. Критерии приёмки

- [ ] Нет английских подписей и сырых ISO-дат в UI.
- [ ] Нет неработающих контролов.
- [ ] Все действия доступны мышью и с клавиатуры.
- [ ] Ошибки не показываются модальными окнами без необходимости.
- [ ] 100–200% DPI, 1024×700 — без обрезки.
- [ ] Тёмная тема не ломает контраст.
- [ ] Пароль не отображается и не логируется.
- [ ] Не-админ не видит чужие задачи и привилегированные действия.
