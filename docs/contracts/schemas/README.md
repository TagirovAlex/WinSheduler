# JSON-схемы контрактов

Каталог для машинночитаемых JSON-схем протокола IPC и моделей данных.

## Назначение

- Единый источник истины для формата сообщений между C++ службой и C# UI.
- Основа для контрактных round-trip тестов в `./tests/contract/`.
- Проверяются в `./scripts/verify.ps1`: каждый `*.json` в этом каталоге должен быть валидным JSON.

## Соглашения

- Имя файла — `<Model>.schema.json` (например, `TaskDto.schema.json`).
- Draft 2020-12 (`$schema: "https://json-schema.org/draft/2020-12/schema"`).
- Все новые поля — необязательные: это требование обратной совместимости из `./docs/contracts/IPC.md`.
- Схемы не содержат секретов и примеров с реальными путями пользователей.

## Статус

Каталог создан в Phase 0 (P0-8). Сами схемы пока не обязательны и появятся в Track G (G-4).
