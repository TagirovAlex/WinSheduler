# Реестр рисков

Обновляется Architect/Integrator. Агенты учитывают риски в своей работе.

| ID | Риск | Вероятность | Влияние | Меры |
|----|------|-------------|---------|------|
| R-01 | Нет CI, параллельные агенты ломают `main` | высокая | высокое | Локальный `./scripts/verify.ps1`, lock сборки, Gatekeeper, merge freeze |
| R-02 | Конфликты правок в общих файлах | средняя | высокое | Матрица владения, Integrator для `config.h`, `main.cpp`, `service.*`, `.sln` |
| R-03 | Сборка C++ недоступна на машине агента | низкая | высокое | VS2022 Community найдена, MSBuild 17.14, vswhere в `ProgramFiles(x86)` |
| R-04 | NuGet restore для xUnit недоступен | средняя | среднее | Fallback на консольный тест-проект без пакетов |
| R-05 | Валидация ACL кастомного `INSTALLDIR` сложна | средняя | высокое | Блокировать небезопасные пути по умолчанию, `ALLOWUNSAFEPATH` только для лаборатории |
| R-06 | Пароли снова окажутся в UI или логах | средняя | критическое | DPAPI SYSTEM в службе, `hasPassword`, security-чеклист, тесты |
| R-07 | Доменная политика запрещает создание локальных групп | средняя | среднее | Fallback: доступ только Administrators, документировать |
| R-08 | Размер self-contained MSI | высокая | низкое | Принять 60–80 МБ, сжатие MSI, опционально ReadyToRun |
| R-09 | WiX не установлен | высокая | среднее | Track F: `dotnet tool install --global wix`, документировать |
| R-10 | Нет сертификата подписи | высокая | среднее | SHA256-манифест, предупреждение SmartScreen, план закупки |
| R-11 | Неоднозначная миграция legacy-задач | средняя | среднее | `owner_sid=S-1-5-18`, админ переназначает; резервная копия перед миграцией |
| R-12 | Задачи не-админа в session 0 без профиля | высокая | среднее | Документировать headless-ограничения; интерактивный режим — отдельный ADR |
| R-13 | Остановка службы убивает задачи | средняя | высокое | Не убивать при graceful stop, помечать `Aborted`, recovery при старте |
| R-14 | Конкуренция SQLite | средняя | высокое | Один writer, `BEGIN IMMEDIATE`, `busy_timeout`, RAII-rollback |
| R-15 | Сложность будущего интерактивного режима | средняя | среднее | `session_mode` зарезервирован, реализация не в v1 |
| R-16 | Утечка секретов через командную строку в логах | средняя | высокое | Редактирование аргументов, запрет паролей в `arguments` |
| R-17 | Подмена exe службы через кастомный путь | средняя | критическое | Проверка ACL родителей, запрет user-writable |
| R-18 | Потеря данных при пересборке | высокая | высокое | `DATADIR` вне `./published`, `publish.ps1` не удаляет данные |
| R-19 | Несовместимость IPC v1 и legacy UI | средняя | среднее | Переходный режим `{Action, Payload}`, одновременное обновление UI и службы |
| R-20 | Отсутствие тестов планировщика | высокая | высокое | Fake clock, табличные тесты, обязательный gate |
| R-21 | VS 2022 17.14 не поддерживает targeting `net10.0` | высокая | высокое | Managed-сборка через `dotnet build` (SDK 10.0.4xx), MSBuild — только для C++; VS 2026 опционально |
| R-22 | .NET 8 EOL 10.11.2026, Server 2016 EOL 12.01.2027 | высокая | высокое | Переход на .NET 10 LTS; зафиксировать даты в README/INSTALL |
| R-23 | Файл экспорта раскрывает пути и имена пользователей | средняя | среднее | Предупреждение в диалоге; секреты исключены; файл не логируется |
| R-24 | Импорт RunAs-задачи без пароля | средняя | высокое | Задача создаётся выключенной + предупреждение «задайте пароль» |
| R-25 | Нагрузка от опроса статуса выполнения | средняя | низкое | `GetHistory(taskId, 1)` на задачу, интервал 2→5 с, лимит 24 ч |
| R-26 | Неоднозначная семантика колонки «Статус» | средняя | низкое | Явные подписи «Выполняется/Ошибка/Включена», тесты VM |
| R-27 | Регрессия WPF при переходе на .NET 10 | средняя | высокое | UI-smoke, ручной чеклист, gate перед релизом |
