# Открытые вопросы

Вопросы, требующие участия владельца проекта. Агенты не блокируются: используют решение по умолчанию, зафиксированное здесь. Обсуждение — после завершения роя.

## Решённые

| № | Вопрос | Решение |
|---|--------|---------|
| 1 | Права группы | Вариант A: только свои задачи, запуск от своего имени; SYSTEM/RunAs — админ |
| 2 | Каталог установки | По умолчанию `%ProgramFiles%/WinSheduler`, кастомный разрешён с валидацией |
| 3 | Каталог данных | Отдельный `DATADIR`, по умолчанию `%ProgramData%/WinSheduler` |
| 4 | Установщик | WiX MSI |
| 5 | .NET Runtime | Self-contained UI |
| 6 | Минимальная ОС | Windows 10 1809+ / Server 2019+ |
| 7 | Язык UI | Русский, строки через `resx` |
| 8 | Подпись | Сертификата нет, шаг-заглушка + SHA256-манифест |
| 9 | CI | Нет, локальный gate + Gatekeeper |
| 10 | Миграция БД | Автоматическая v1→v2 |
| 11 | Параллельность | Максимальная после Phase 0, с разделением файлов |
| 12 | Интерактивные задачи | Только headless в v1; `session_mode` резервируется |

## Открытые (решение по умолчанию)

| № | Вопрос | По умолчанию | Влияние |
|---|--------|--------------|---------|
| O-1 | Базовая версия продукта | `1.2.0` | Версии сборок и MSI; можно изменить до F-1 |

| O-4 | Владелец legacy-задач при миграции | `S-1-5-18` (SYSTEM), админ может переназначить | Кто видит старые задачи после обновления |
| O-5 | Retention | История 1000 на задачу, вывод 30 дней, аудит 180 дней | Размер БД и диска |
| O-6 | Небезопасный `INSTALLDIR` | Блокировать; `ALLOWUNSAFEPATH=1` только для лаборатории | Безопасность установки |
| O-7 | Server Core | Служба поддерживается; UI требует Desktop Experience | Матрица поддерживаемых ОС |
| O-8 | Пути в MSI | В примерах прямые слэши; Windows Installer нормализует | Документация и silent install |

| O-21 | Установка WiX | Не устанавливать из сети без разрешения; MSI собирается после `dotnet tool install --global wix` | Сборка установщика |
