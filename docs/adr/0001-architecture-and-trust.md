# ADR 0001 — Архитектура и модель доверия

Статус: принято.
Дата: 2026-11-01.

## Контекст

Служба работает от `LocalSystem`, UI — от обычного пользователя. Нужно исключить повышение привилегий, утечку учётных данных и обеспечить работу не-администраторов без выдачи им прав администратора.

## Решения

1. Группа `WinSheduler Users` — только маркер доступа к IPC, без Windows-привилегий.
2. Не-администратор может управлять только своими задачами и запускать их от своего имени.
3. `RunAsUser`, `RunAsDomain`, пароли и задачи от SYSTEM — только администраторы.
4. Не-админская задача запускается токеном клиента, полученным через `ImpersonateNamedPipeClient` и `DuplicateTokenEx(TokenPrimary)`.
5. Администратор без elevation имеет filtered token и обрабатывается как оператор; привилегированные действия требуют перезапуска UI через `runas`.
6. Секреты шифруются в службе `CryptProtectData` с `CRYPTPROTECT_SYSTEM`; UI никогда не шифрует и не получает blob.
7. IPC: явный SDDL, `PIPE_REJECT_REMOTE_CLIENTS`, лимит инстансов, таймаут, лимит кадра, лимит глубины JSON.
8. Установка — только в каталог, недоступный на запись не-администраторам; проверяются ACL родителей.
9. Данные — отдельно от программы, в `DATADIR` с ACL `SYSTEM`/`Administrators`.
10. Только headless-задачи; `session_mode` резервируется под будущий интерактивный режим.
11. Аудит всех мутаций и `RunNow`.
12. Подпись кода отложена; выпускается SHA256-манифест.

## Последствия

- Появляется `owner_sid` и фильтрация по владельцу.
- Появляется `IAuthPolicy` и проверка прав на каждое действие.
- UI должен уметь показывать роль и перезапускаться с elevation.
- Не-админские задачи не могут использовать чужой профиль и SYSTEM.
- Интерактивные задачи потребуют отдельного ADR и реализации `session_mode=ActiveUser`.
- Усложняется установщик: ACL, группа, проверка путей.

## Альтернативы

- Выдать группе право создавать SYSTEM-задачи — отклонено: группа стала бы эквивалентом администратора.
- Запускать UI от администратора — отклонено: постоянный elevation GUI повышает риск.
- Хранить пароли в `CRYPTPROTECT_LOCAL_MACHINE` — отклонено: любой пользователь машины может расшифровать.
