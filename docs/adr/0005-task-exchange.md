# ADR 0005 — Экспорт и импорт задач

Статус: принято.
Дата: 2026-11-06.

## Контекст

Нужен перенос задач между установками WinSheduler: одна задача или несколько
выбранных. Служба уже предоставляет `GetTask`, `CreateTask`, `UpdateTask`;
кадр IPC ограничен 1 МиБ. Пароли хранятся в службе через DPAPI
`CRYPTPROTECT_SYSTEM` и наружу не отдаются.

## Решения

1. Обмен выполняет UI через существующие действия IPC, без новых действий
   и без изменений службы/БД.
2. Формат — JSON-документ `winsheduler.tasks`, `formatVersion = 1`,
   расширение `*.wstasks.json`, UTF-8 без BOM.
3. Экспорт — только выбранные задачи (одна или несколько); «все видимые»
   в v1 не делаем.
4. Секреты (`password`, `encryptedPassword`, `runAsPasswordEncrypted`),
   `owner`, `createdAt`, `modifiedAt` в файл не попадают.
5. Импорт по умолчанию — «копия» с новыми GUID; режимы `skip` и `overwrite`
   доступны явно. `overwrite` затрагивает только свои задачи.
6. При импорте `timeWindows[].id` очищаются: служба генерирует новые,
   иначе повторный импорт копии даёт конфликт PK.
7. Если `hasPassword = true`, а пароль не задан, задача создаётся выключенной
   с предупреждением.
8. Владелец импортированной задачи — импортирующий пользователь.
9. Лимиты: файл 8 МиБ, 5000 задач, 1000 триггеров на задачу, строки 64 КиБ.
10. Аудит — существующие записи `CreateTask`/`UpdateTask`; экспорт пишет
    только локальную строку лога UI.

## Последствия

- Появляется контракт `./docs/contracts/EXCHANGE.md` и модели
  `TaskExchange*` в `WinSheduler.Shared`.
- UI получает сервис обмена и диалоги; `MainWindow` — multi-select и команды.
- Пароли при переносе нужно задавать повторно — это осознанное ограничение.
- Сохранение исходного владельца потребует нового IPC-действия и отдельного
  ADR.

## Альтернативы

- Серверный пакетный экспорт/импорт — отклонено: лимит кадра 1 МиБ,
  новая поверхность атаки и дублирование валидации.
- Включить DPAPI-блоб в файл — отклонено: бесполезен на другой машине
  и раскрывает секрет.
- Бинарный/SQLite-формат — отклонено: сложнее проверить и отладить.
