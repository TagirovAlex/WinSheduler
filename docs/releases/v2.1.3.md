# WinSheduler 2.1.3

Дата: 2026-11-09.
Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.3

## Главное

Добавлены проверка и автоматическая установка обновлений.

## Что нового

- Меню «Справка → Проверить обновления»; пункт виден, только если
  в сборке задан `UpdateUrl`.
- Проверка при старте не чаще раза в неделю и вручную.
- Манифест проверяется по версии, SHA256, размеру и UNC-пути.
- MSI копируется локально; проверяются SHA256 и Authenticode-подпись.
- Перед установкой предупреждение о выполняющихся задачах и резервная
  копия `scheduler.db` на шару.
- Установка тихая (`msiexec /qn /norestart`) с перезапуском UI.
- Без прав администратора предлагается перезапуск с повышением.

## Установка

```bat
msiexec /i WinSheduler-2.1.3.msi
```

Тихая установка:

```bat
msiexec /i WinSheduler-2.1.3.msi /qn /l*v install.log
```

Кастомные каталоги:

```bat
msiexec /i WinSheduler-2.1.3.msi INSTALLDIR="d:/Apps/WinSheduler" DATADIR="d:/WinShedulerData" /qn
```

## Требования

- Windows 10 1607+ / Windows Server 2016+ (x64).
- UI — Desktop Experience и интерактивная сессия.
- .NET Runtime не требуется (self-contained).
