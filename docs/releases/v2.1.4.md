# WinSheduler 2.1.4

Дата: 2026-11-09.
Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.4

## Главное

Проверка обновлений при каждом запуске UI. Установка предлагается только
при запуске от администратора; обычный пользователь видит уведомление.

## Что нового

- При старте UI читает `latest.json` и сравнивает версию.
- Под обычным пользователем — только уведомление о новой версии.
- Под администратором — предложение установить с размером обновления.
- Манифест проверяется по версии, SHA256, размеру и UNC-пути.
- MSI копируется локально; проверяются SHA256 и Authenticode-подпись.
- Перед установкой предупреждение о выполняющихся задачах и резервная
  копия `scheduler.db` на шару.
- Установка тихая (`msiexec /qn /norestart`) с перезапуском UI.

## Установка

```bat
msiexec /i WinSheduler-2.1.4.msi
```

Тихая установка:

```bat
msiexec /i WinSheduler-2.1.4.msi /qn /l*v install.log
```

Кастомные каталоги:

```bat
msiexec /i WinSheduler-2.1.4.msi INSTALLDIR="d:/Apps/WinSheduler" DATADIR="d:/WinShedulerData" /qn
```

## Требования

- Windows 10 1607+ / Windows Server 2016+ (x64).
- UI — Desktop Experience и интерактивная сессия.
- .NET Runtime не требуется (self-contained).

## Примечания

- В локальной сети MSI и бинарники подписаны; сборка на GitHub —
  без подписи.
- В сборке для GitHub `UpdateUrl` не задан, пункт проверки обновлений
  скрыт.
- Обновление необязательное; установку можно отложить.
- Данные в `DATADIR` при обновлении и удалении сохраняются.
