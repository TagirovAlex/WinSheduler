# WinSheduler 2.1.0

Дата: 2026-11-06.
Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.0

## Что нового

- **Экспорт и импорт задач.** Одна задача или несколько выбранных,
  формат `*.wstasks.json`. Импорт с предпросмотром и режимами «копия»,
  «пропустить», «обновить свои». Пароли не экспортируются и не импортируются.
- **Живой статус выполнения.** После ручного запуска список сам обновляет
  статус: «Выполняется» → «Завершена»/«Ошибка». Ручной F5 больше не нужен.
- **.NET 10 LTS.** UI остаётся self-contained: .NET Runtime на целевой машине
  не требуется.
- **Windows Server 2016.** Минимальная ОС — Windows 10 1607 / Server 2016
  (build 14393). UI требует Desktop Experience; служба работает и на Server Core.
- Иконки экспорта/импорта в общем стиле приложения.

## Установка

```bat
msiexec /i WinSheduler.msi
```

Тихая установка:

```bat
msiexec /i WinSheduler.msi /qn /l*v install.log
```

Кастомные каталоги:

```bat
msiexec /i WinSheduler.msi INSTALLDIR="d:/Apps/WinSheduler" DATADIR="d:/WinShedulerData" /qn
```

## Требования

- Windows 10 1607+ / Windows Server 2016+ (x64).
- UI — Desktop Experience и интерактивная сессия.
- .NET Runtime не требуется (self-contained).
- Для сборки: Visual Studio 2022 Build Tools (MSVC v143), .NET 10 SDK, WiX 5.

## Примечания

- MSI не подписан: SmartScreen может предупредить о неизвестном издателе.
  Проверяйте SHA256 по `SHA256SUMS.txt`.
- Данные в `DATADIR` при обновлении и удалении сохраняются по умолчанию.
- Пароли RunAs при переносе задач нужно задать заново: они не покидают
  исходную машину.
- Только headless-задачи; интерактивный режим зарезервирован на будущее.
