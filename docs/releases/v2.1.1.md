# WinSheduler 2.1.1

Дата: 2026-11-07.
Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.1

Косметический релиз: обновлён интерфейс, поведение планировщика не менялось.

## Что нового

- Главное меню: **Файл / Вид / Действия / Справка**.
  - «Файл» → «Выход».
  - «Вид» → «Обновить», «Сбросить фильтр».
  - «Действия» → «Новое задание», «Импорт задания».
  - «Справка» → «Помощь» (F1), «О программе».
- Панель действий в одном ряду: добавить, изменить, удалить,
  включить/отключить, журнал, запустить, обновить, экспорт, импорт,
  диагностика. Все кнопки видны, без выпадающего overflow.
- Поиск и фильтр — второй строкой слева, одинаковой высоты, выровнены
  по вертикали.
- Диагностика перенесена из статус-бара в панель действий.
- Баннеры ошибок больше не оставляют пустого места: скрытые баннеры
  не занимают высоту.
- Адаптивная раскладка:
  - начальная ширина окна равна ширине строки кнопок;
  - окно нельзя сузить меньше этой строки;
  - таблица задач тянется звёздными колонками;
  - при maximise содержимое заполняет экран без чёрных полос.
- Улучшена работа XAML-дизайнера VS 2026: design-time guard’ы,
  явные pack URI иконок, стабильная раскладка.

## Установка

```bat
msiexec /i WinSheduler.msi
```

Тихая установка:

```bat
msiexec /i WinSheduler.msi /qn /l*v install.log
```

Кастомные каталоги:

```bat
msiexec /i WinSheduler.msi INSTALLDIR="d:/Apps/WinSheduler" DATADIR="d:/WinShedulerData" /qn
```

## Требования

- Windows 10 1607+ / Windows Server 2016+ (x64).
- UI — Desktop Experience и интерактивная сессия.
- .NET Runtime не требуется (self-contained).
- Для сборки: Visual Studio 2022/2026 Build Tools, .NET 10 SDK, WiX 5.

## Примечания

- MSI не подписан: SmartScreen может предупредить о неизвестном издателе.
  Проверяйте SHA256 по `SHA256SUMS.txt`.
- Данные в `DATADIR` при обновлении и удалении сохраняются по умолчанию.
- Только headless-задачи; интерактивный режим зарезервирован.
