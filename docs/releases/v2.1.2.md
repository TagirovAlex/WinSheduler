# WinSheduler 2.1.2

Дата: 2026-11-09.
Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.2

## Главное

Исправлено планирование задач после импорта и любых изменений через UI.

## Что было

Планировщик держит расписание в кэше. После `CreateTask`, `UpdateTask`,
`DeleteTask` и `SetTaskEnabled` кэш не сбрасывался: новые и импортированные
задачи не запускались по расписанию до перезапуска службы. Ручной `RunNow`
работал, потому что идёт мимо расписания.

## Что исправлено

- IPC после создания, изменения, удаления и включения/выключения задачи
  уведомляет планировщик (`TaskChanged`).
- Планировщик сбрасывает кэш расписания и очищает состояние слотов задачи.
- Импортированные задачи начинают планироваться сразу, без перезапуска службы.
- Добавлен регрессионный тест на новую задачу после старта планировщика.

## Проверка обновлений

В меню «Справка → Проверить обновления» отображается версия на шаре.
Пункт виден только в сборке, где задан `UpdateUrl`. При подтверждении
проверяются SHA256 и подпись MSI, БД копируется на шару, затем MSI
устанавливается тихо и UI перезапускается.

## Установка

```bat
msiexec /i WinSheduler.msi
```

Тихая установка:

```bat
msiexec /i WinSheduler.msi /qn /l*v install.log
```

Кастомные каталоги:

```bat
msiexec /i WinSheduler.msi INSTALLDIR="d:/Apps/WinSheduler" DATADIR="d:/WinShedulerData" /qn
```

## Требования

- Windows 10 1607+ / Windows Server 2016+ (x64).
- UI — Desktop Experience и интерактивная сессия.
- .NET Runtime не требуется (self-contained).

## Контрольная сумма

```
3A91AA06592713AB5CE11E4F958C9C3A9314DC49A65F10FF11AA1552CA7F13FA  WinSheduler-2.1.2.msi
```

MSI, `WinShedulerSvc.exe` и `WinSheduler.UI.exe` подписаны Authenticode
(AD CS, Code Signing). Проверка подписи:

```powershell
Get-AuthenticodeSignature .\WinSheduler-2.1.2.msi | Format-List Status,SignerCertificate
```

## Примечания

- Импортированные задачи с `hasPassword = true` создаются выключенными:
  задайте пароль и включите задачу.
- Обновление необязательное: администратор устанавливает MSI вручную.
- Данные в `DATADIR` при обновлении и удалении сохраняются.
- Комплект обновления: `\\intsrvfs\winsheduler`
  (`WinSheduler-2.1.2.msi`, `latest.json`, `SHA256SUMS.txt`).
