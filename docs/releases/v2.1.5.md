# WinSheduler 2.1.5

Дата: 2026-11-12.
Релиз: https://github.com/TagirovAlex/WinSheduler/releases/tag/v2.1.5

## Что нового

- Кнопка «Остановить» принудительно завершает выбранное запущенное задание.
- В таблице появилась колонка «Следующий запуск».
- Пункт «Включить/отключить» переименован в «Вкл/Выкл».
- «Экспорт», «Импорт» и «Диагностика» перенесены в строку поиска и фильтра.
- Окно открывается шириной, при которой видны все колонки таблицы.

## Установка

```bat
msiexec /i WinSheduler-2.1.5.msi
```

Тихая установка:

```bat
msiexec /i WinSheduler-2.1.5.msi /qn /l*v install.log
```
