# E2E-тесты

Каталог для сквозных проверок «установка → служба → UI → задача».
Стратегия — `./tests/README.md`, чеклист установки — `./docs/contracts/INSTALL.md`, п. 13.

## Статус

Каркас создан в Track G (G-1). Сценарии появятся после готовности треков F и E
(I-6). До этого E2E выполняются вручную по чеклисту `INSTALL.md`.

## Планируемые сценарии

| ID | Сценарий | Зависит |
|----|----------|---------|
| E2E-1 | Установка MSI на чистую ВМ, служба запущена, `Ping`/`GetStatus` отвечают | F-1…F-5 |
| E2E-2 | Создание задачи оператором, `RunNow`, запись истории | B-5, A-9 |
| E2E-3 | Задача от SYSTEM видна только администратору | B-2, B-12 |
| E2E-4 | Upgrade MSI: задачи и история сохранены | F-8 |
| E2E-5 | Uninstall с `KEEPDATA=1`: данные сохранены, служба удалена | F-7 |
| E2E-6 | UI: первый запуск без службы, баннер и повтор | D-4, E-6 |
| E2E-7 | UI: создание/правка/запуск задачи через экраны | E-1…E-4 |
| E2E-8 | DPI 100–200%, 1024×700, тёмная тема | E-8 |

## Правила

- Сценарии не запускаются в обычном gate: нужны права администратора и чистая ВМ.
- Скрипты используют только `./temp/e2e/` и не трогают `./published/**`.
- Результат фиксируется в `./docs/status/gate.md` с датой и версией MSI.
- Секреты (пароли RunAs) в логи сценариев не попадают.
