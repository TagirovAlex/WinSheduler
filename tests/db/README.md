# Тесты трека C (хранение)

Тесты проверяют схему v2, миграцию v1 → v2, репозитории, транзакции,
retention, валидацию пути, резервное копирование, планы запросов и бенчмарк
1000 задач. Контракты — `./docs/contracts/DB.md`, `./docs/contracts/SECURITY.md`.

## Состав

| Файл | Назначение |
|------|------------|
| `db_tests.cpp` | Все проверки C-1…C-8, включая бенчмарк 1000 задач |
| `db_tests.vcxproj` | Самодостаточный проект: модули трека C, `json.cpp`, `sqlite3.c` |
| `run.ps1` | Сборка и запуск с общим lock-файлом сборки |

## Запуск

```
./tests/db/run.ps1
```

Скрипт собирает проект в `./tests/db/bin/<Configuration>/` и запускает
`WinShedulerDbTests.exe` с корнем проекта как рабочим каталогом.
Временные файлы создаются только в `./temp/c/db-tests/`.

## Статус интеграции в gate

Проект пока не входит в `./WinSheduler.sln` и не вызывается из
`./scripts/verify.ps1`. Это зона Integrator (решение) и Track G (G-2 —
C++ тест-харнесс). Запрос зафиксирован в `./docs/status/c-requests.md`.
