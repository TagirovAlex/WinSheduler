# Контрактные тесты

Каталог для контрактных тестов IPC и хранения.

## Что здесь будет

- JSON-схемы сообщений IPC (запрос, ответ, ошибка) и моделей (`TaskDto`, `TimeWindowDto`, `RunHistoryDto`).
- Round-trip тесты: сериализация модели в JSON и обратный разбор без потери полей.
- Проверка обратной совместимости: отсутствие необязательных полей не ломает разбор.
- Фикстуры миграции БД v1 → v2 (Track C, задача C-7).

## Правила

- Источник истины — `./docs/contracts/IPC.md` и `./docs/contracts/DB.md`.
  Схемы лежат в `./docs/contracts/schemas/` и используются обеими сторонами (C++ служба и C# UI).
- Схемы и тесты меняются только вместе с контрактом и ADR.
- Тесты должны быть детерминированными и не обращаться к сети.

## Статус

Каркас создан в Phase 0 (P0-8). Сами схемы и тесты появятся в Track G (G-4).
