# Тесты UI (трек D)

Проект xUnit для фундамента UI: ViewModel, команды, конвертеры, локализация,
IPC-клиент, дизайн-система и состояние окна.

## Запуск

```
dotnet test ./tests/ui/WinSheduler.UI.Tests.csproj -c Release
```

Проект пока не входит в `./WinSheduler.sln` (файл решения — зона Integrator),
поэтому `./scripts/verify.ps1` его не собирает. Запрос на добавление в решение —
в `./docs/status/d-requests.md`.

## Особенности

- ViewModel рассчитан на UI-поток: тесты завершают асинхронные операции на своём
  потоке, поэтому коллекции и `ICollectionView` не пересекаются между потоками.
- Тест дизайн-системы создаёт `Application` в отдельном STA-потоке: WPF требует STA.
  В процессе допустим только один экземпляр `Application`, поэтому все проверки
  словарей собраны в одном тесте.
- Тесты IPC поднимают собственный именованный канал с уникальным именем,
  служба WinSheduler для них не нужна.
